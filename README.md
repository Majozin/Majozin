## 🚀 Sobre mim

Sou entusiasta de tecnologia e desenvolvimento de soluções próprias, com interesse em sistemas web, automação de processos, infraestrutura **self-hosted** e inteligência artificial aplicada ao desenvolvimento.

Gosto de acompanhar todo o ciclo de um projeto: **planejamento, prototipação, implementação, testes, implantação e manutenção**.

- 🏗️ Desenvolvimento de aplicações e sistemas de gestão
- 🐳 Infraestrutura Linux, Docker e serviços auto-hospedados
- ⚙️ Automação, APIs e integrações entre serviços
- 🎨 Organização de interfaces e experiência do usuário
- 🤖 Inteligência artificial como apoio ao desenvolvimento de software
