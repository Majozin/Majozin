# Direção visual do perfil

Perfil pessoal em português, compatível com GitHub Markdown. Apresentação breve, projetos e tecnologias; sem notas operacionais no README.

Paleta: superfície #F2F7FC, cabeçalho #EAF2FA, texto #203C55, secundário #526C82, destaque #547FA5, borda #C9D9E9. SVGs locais usam esses valores; o Markdown herda o tema do GitHub.
Tipografia: Trebuchet MS/Arial no nome; Arial nos cartões; fontes nativas do GitHub no corpo. Assinatura: M geométrico sobre grade, associado a construção de sistemas.

Cartões de 390 px com barras proporcionais e texto alternativo. A métrica automática é explicitamente “Issues concluídas”, nunca conclusão do produto. Sem métricas: lista compacta, sem barras vazias. Nomes e indicadores agregados são os únicos dados privados publicados. Falha de consulta preserva o painel anterior.

Gerador: scripts/render_projects.py. Coleta: scripts/update_private_projects.py. O workflow versiona README e assets/projects juntos. Não incluir serviços externos de estatísticas, scripts em SVG, animações ou descrições internas no perfil.

Referências de organização: artigo Alura sobre README de perfil e template Editorial Card de beydemirfurkan/awesome-github-profile. Composição e ativos originais.
